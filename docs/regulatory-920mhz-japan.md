# 920 MHz 帯（802.11ah）の国内制度と RoadWeave への影響

更新日: 2026-09-06  
一次資料: 総務省「920MHz帯小電力無線システムの広帯域化」（令和 4 年 9 月 5 日、総務省令第 60 号の概要、
https://www.soumu.go.jp/main_content/000833183.pdf 3 ページ目の技術基準表）、802.11ah 推進協議会 実装ガイド（https://www.11ahpc.org/pdf/11ah_guide.pdf）。
本書は概要資料の読み取りであり、最終判断は無線設備規則本文・告示と認証機関で確認する。

## 1. 中出力型アクティブ系小電力無線（20 mW）の技術基準（令和 4 年改正後）

| 項目 | 920.5〜923.5 MHz | 920.5〜928.1 MHz |
|---|---|---|
| 占有周波数帯幅 | 200 kHz × n（n = 1〜15、最大 3 MHz） | 200 kHz × n（n = 1〜20、最大 4 MHz） |
| 空中線電力 | 20 mW 以下（13 dBm） | 同左 |
| 空中線利得 | 3 dBi 以下 | 同左 |
| 周波数共用方式 | キャリアセンス | キャリアセンス |
| キャリアセンス受信時間 | 5 ms 以上 | 128 µs 以上 |
| 送信時間 | 4 s 以内（4 s 以内の再送信は特例あり） | 400 ms 以内 |
| 休止時間 | 50 ms 以上（再送信等の特例あり） | 2 ms 以上 |
| 送信時間の総和（無線設備あたり） | **制限なし** | 360 s/h 以下（Duty 10%、複数チャネル切替時は 720 s/h） |
| 送信時間の総和（チャネルあたり） | **制限なし** | 360 s/h 以下 |

改正で変わったのは束ねられる単位チャネル数（1 MHz → 4 MHz）だけで、送信時間・休止時間・総和の枠組みは従来の
特小（ARIB STD-T108）と同じ 2 系統が維持されている。

## 2. RoadWeave にとっての結論

1. **音声ストリーミングは 920.5〜923.5 MHz 側なら制度上成立する。** 総送信時間の制限がなく、制約は「1 回の送信 4 s 以内、
   休止 50 ms 以上、送信前に 5 ms のキャリアセンス」。802.11ah のフレームは ms 単位なので送信時間は問題にならない。
   PTT の連続発話（最大 120 s）も、MAC 層が 4 s 以内のバーストで区切っていれば適合する。
2. **923.5 MHz を超える帯域（4 MHz チャネルを含む配置）は Duty 10% が掛かる。** 音声用途では使わない。
   HaLow の 1 MHz / 2 MHz チャネルを 920.5〜923.5 MHz の中に収める設定を factory lock する（Issue #10 の「factory lock 方針」）。
3. 5 ms のキャリアセンスは HaLow の CCA より長い。**モジュール（MRF61_A）の JP 用 BCF / driver がこの条件を実装しているか**を
   MegaChips に確認する。実装されていれば application 側の対応は不要。
4. 出力 13 dBm・利得 3 dBi 以下は前回議論のとおり。車載外部アンテナはこの利得枠内で、モジュール認証に登録されたものに限る
   （AHPC ガイド: 未登録アンテナはモジュールへの追加認証が必要）。
5. 250 mW の登録局（簡易無線局）系は別制度。免許不要で売る製品としては 20 mW 枠を前提にする。

## 3. 認証（AHPC ガイド 8〜10 ページ）

- 工事設計認証取得済みモジュール（MRF61_A）を搭載する場合、**機器側での無線認証は不要**。ただし未登録アンテナを使うなら
  モジュールへのアンテナ追加認証が必要。
- 試作機・少量なら技術基準適合証明（機器単体ごと）という選択肢もある。
- 認証機関一覧: https://www.tele.soumu.go.jp/j/sys/equ/tech/
- Wi-Fi CERTIFIED HaLow は相互接続性の任意認定で、電波法とは別。

## 4. 未確認事項（Issue #10 で確認）

- MRF61_A の JP 動作モードで、キャリアセンス 5 ms / 送信 4 s / 休止 50 ms が driver / firmware 側で保証されるか
- 921〜927 MHz（MRF61_A の記載）のうち、923.5 MHz 以下に収まるチャネル番号と op-class
- WM6180 / HC01P（902〜928 MHz 系）を国内で試験する場合の適法な方法（conducted / shielded）は変わらない
