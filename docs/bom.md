# BOM v2 と数量別コスト仮定

更新日: 2026-09-06（v1: 2026-09-02）  
通貨: 日本円、税別。[製品定義 v2](product-definition-v2.md) に合わせて 2.8 インチ静電容量タッチ表示と MRF61_A（日本ライン）を主構成にした。

## 1. 読み方

これは発注見積ではなく、設計判断のための should-cost モデルである。100/1,000/10,000 台の各列は同一設計をその数量で一括生産した場合の 1 台当たり仮定。
為替は **USD 1 = JPY 150**、通常歩留まり、標準梱包を想定する。

含むもの: 電子部品、PCB、実装、筐体（100 台は切削/3D プリント、1,000 台以上は成形）、工場機能試験、標準梱包、歩留まり・初期不良準備金。
含まないもの: 開発人件費、試作、治具 NRE、金型 NRE、認証・EMC 試験、物流、関税、販売手数料、消費税、microSD カード、車外マグネットアンテナ、車載電源アダプタ。

## 3. HC01 V2 ライン（海外向け / 開発主系、参考）

MRF61_A の行を HT-HC01 V2（1,800 / 1,450 / 1,200 円）に置き換え、認証アンテナを汎用品（950 → 700 円級）にした場合:
**計画値 17,100 / 9,950 / 6,750 円**。日本国内では販売できない。

## 4. 変更の内訳（v1 → v2）

- 表示を 1.47 インチ非タッチから 2.8 インチ静電容量タッチへ: +920 / +580 / +390 円（driver 込み）
- スピーカー・ボタン・筐体・機械部品の格上げ（モックの「大きな PTT」「高出力スピーカー」「IP54」）: +450 / +270 / +170 円
- MRF61_A は v1 の日本ライン仮定と同じ（RFQ 待ち）

## 6. NRE とキャッシュ上の注意

| 項目 | 初期レンジ仮定 |
|---|---:|
| Rev.A 回路/PCB 試作 2〜10 台 | 50〜150 万円 |
| RF/audio/GNSS 試験治具 | 30〜100 万円 |
| 認証（アンテナ追加登録、PSE、EMC 自主試験） | 30〜100 万円 |
| 射出成形金型 | 300〜800 万円 |
| 初回量産の不具合対応準備 | 初回発注額の 5〜10% |

100 台では金型を償却しない。1,000 台の判断時に金型を発注する。

## 8. コストダウン順序

1. MRF61_A、表示、battery、antenna を RFQ して実価格に置換
2. EVT で電源と audio の過剰 spec を削る
3. 4 層基板面積と実装面数の最適化
4. 1,000 台以上で custom enclosure、speaker chamber、flex/connector 削減
5. 10,000 台の見込みが立ってから ESP32 module-to-chip 化を検討
