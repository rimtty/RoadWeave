# BOMと数量別コスト仮定

更新日: 2026-09-02  
通貨: 日本円、税別

## 1. 読み方

これは発注見積ではなく、設計判断のためのshould-costモデルである。100/1,000/10,000台の各列は、同一設計をその数量で一括生産した場合の1台当たり仮定。為替は **USD 1 = JPY 150**、通常歩留まり、標準梱包を想定する。

含むもの:

- 電子部品、PCB、実装
- 量産筐体または少量筐体
- 工場機能試験、標準梱包
- 歩留まり・初期不良準備金

含まないもの:

- 開発人件費、試作、治具NRE、金型NRE
- 各国認証・EMC試験、法務、PL保険
- 国際/国内物流、関税、販売手数料、消費税
- microSDカード、車外マグネットアンテナ、車載電源アダプタ

## 3. MRF61_A 日本ライン

MRF61_Aは公開少量価格を確認できないため、次のモジュール単価をRFQ前のプレースホルダーにする。

|---|---:|---:|---:|

他のBOMを共通とした比較:

|  | 100台 | 1,000台 | 10,000台 |
|---|---:|---:|---:|
| MRF61_Aライン想定COGS/台 | 18,000 | 10,700 | 7,400 |
| HC01 V2比 | +2,500 | +1,600 | +1,100 |

この差額の確度は低い。MegaChipsへのRFQ、指定アンテナ、最低発注数、国内製造試験条件が得られた時点で更新する。MRF61_AはMM6108、SDIO/SPI、3.3 V単一電源、最大13 dBm、見通し約1 km、技適取得済みとされる。[MegaChips製品情報](https://www.megachips.co.jp/product/modules/wifi-halow/rf-modules/)

## 4. 売価29,800円の粗利感度

「粗利」は会社の利益ではない。ここから開発費、認証、物流、決済、販売店、サポート、返品、税を支払う。

| HC01 V2ライン | 100台 | 1,000台 | 10,000台 |
|---|---:|---:|---:|
| 想定COGS/台 | 15,500 | 9,100 | 6,300 |
| 直販売価（税別例） | 29,800 | 29,800 | 29,800 |
| 粗利額/台 | 14,300 | 20,700 | 23,500 |
| 粗利率 | 48.0% | 69.5% | 78.9% |
| 全数直販時の粗利総額 | 143万円 | 2,070万円 | 2億3,500万円 |

販売店へ卸す場合はこの表を使わない。たとえば売価29,800円、卸値が売価の60%ならメーカー売上は17,880円/台であり、100台時COGSでは粗利余地が極端に小さい。

## 5. NREとキャッシュ上の注意

| 項目 | 初期レンジ仮定 |
|---|---:|
| Rev.A回路/PCB試作2〜10台 | 50万〜150万円 |
| RF/audio/GNSS試験治具 | 30万〜100万円 |
| 射出成形金型 | 300万〜800万円 |
| EMC/安全/無線関連の評価 | 地域・構成確定後に見積 |
| 初回量産の不具合対応準備 | 初回発注額の5〜10%を別枠 |

100台では量産金型を償却しにくい。PoC/EVTは3D printまたは加工筐体、1,000台へ進む判断時に金型を発注するのが安全。

## 6. コストダウン順序

1. HC01/MRF61、LCD、battery、antennaをRFQして実価格に置換
2. EVTで電源とaudioの過剰specを削る
3. ESP32-S3 moduleを維持したまま4層基板面積と実装面数を最適化
4. 1,000台以上でcustom enclosure、speaker chamber、flex/connector削減
5. 10,000台の見込みが立ってからESP32 module-to-chip化を検討。認証・RF再設計費と比較し、単価だけで判断しない
