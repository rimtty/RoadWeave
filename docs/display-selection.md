# ディスプレイ選定（タッチ付き 2.8 インチ）

更新日: 2026-09-06

## 要件

- 走行中の操作は物理 PTT と大ボタンが主。タッチは停車時の設定・グループ操作・地図の pan/zoom 用。
- 車内の直射日光下で読めること（IPS、輝度 300 cd/m² 以上が望ましい）。手袋・振動下では静電容量式が有利、抵抗膜式は手袋で使える。
- Rev.A PCB に載せる前提で、**同じコントローラ（ILI9341 / ST7789）で「ピンヘッダ付きモジュール（PoC）」と「FPC 直付け（PCB）」の両方が入手できる**こと。
- 1.47 インチ 172×320 の初期案は「隊列と発話者の表示」には足りるが、地図とタッチ操作には狭い。2.8 インチ 240×320 を第一候補にする。

## 候補

| 段階 | 候補 | 解像度 / IF | タッチ | 備考 |
|---|---|---|---|---|
| PoC（今すぐ） | 2.8" ILI9341 SPI モジュール（ピンヘッダ、XPT2046 抵抗膜タッチ付き、約 ¥900） | 240×320 / SPI 40 MHz | XPT2046（SPI、同一バス） | ESP-IDF に `esp_lcd_ili9341` と `esp_lcd_touch_xpt2046` あり。LVGL 検証に十分 |
| PoC 代替 | ESP32-2432S028（ESP32 + 2.8" ILI9341 + タッチ、約 ¥1,800） | 同上 | XPT2046 | ESP32 クラシック搭載で XIAO とは別 MCU。**UI だけ**を先に作る開発ボードとしては便利だが、製品コードの検証には使わない |
| Rev.A PCB | 2.8" IPS 240×320 ILI9341（SPI、FPC 18〜40 pin）+ 静電容量タッチ FT6336 / FT5x06（I2C） | SPI + I2C | 静電容量 | ドライバは `esp_lcd_touch_ft5x06`。コントローラが同じなので UI コードは PoC からそのまま |
| Rev.A 代替 | 2.8" ST7789V 240×320 | 同上 | 同上 | `esp_lcd_st7789`。ILI9341 と API 互換 |

選定の決め手は「日光下の輝度」と「FPC 品の入手性」なので、Rev.A 前に 2〜3 種を実物で比較する。
高輝度（500 cd/m² 級）品は同じ ILI9341 で存在するが単価が上がる。

## ピン予算（Rev.A、docs/gpio-allocation.md に反映予定）

- LCD SPI: SCK / MOSI（+ MISO は不要）、CS、DC、RESET、BL（PWM 20 kHz 以上）= 6 本
- タッチ: I2C SDA / SCL + INT = 3 本（抵抗膜 XPT2046 なら SPI 共用 + CS + IRQ）
- 1.47 インチ案から +3 本程度。ESP32-S3-WROOM では余裕がある。

## ソフト

- LVGL 9 + `esp_lvgl_port`（Espressif 公式 glue）。SPI 40 MHz、部分描画（1/10 画面のダブルバッファ）で 25〜30 fps。
- `firmware/experiments/ui_lvgl` に、隊列リスト / レーダー / 通話状態の 3 画面を **ディスプレイなしでもビルドできる形**で先行実装
  （データはシミュレーション）。ディスプレイ到着後は menuconfig でピンを合わせるだけ。
- 画面は core 1、音声と無線は core 0（architecture.md の方針）。
