# 6台音声：PTTから最初の再生までの測定準備

## 測るもの

`tools/voice_latency_analyze.py` は、**PTTが押された瞬間から、各受信車の音声出力に試験音が現れるまで**を測る。PTT信号と受信音声を同じ多チャンネル録音機の共通クロックで記録するため、端末間の時計合わせやUSBシリアルログの到着時刻に依存しない。測定器の窓幅は既定5 ms。結果は受信車ごとの全試行、未着、p50/p95/p99、150 ms判定をJSONで残す。

この測定は音声の**出力電気信号**までを基本とする。スピーカーとマイクを通した聴感上の遅延を評価する場合は、各スピーカーに設置した測定マイクを同じ録音機へ接続し、音響経路の遅延・周囲雑音も含む別結果として扱う。

## 実機の構成

1. 先頭車をHost/AP、別の1台を発話車、残りを受信車とする。Host自身の再生出力も受信対象に含める。試験条件として台数、1/2 MHz、チャネル、距離、アンテナ、送信出力設定、codec、音声frame長、ソフトウェア版を記録する。
2. 発話車のマイクへ連続1 kHz試験音を入れる。PTTは試験操作器で30回以上押し、各押下の前に音声出力が十分静かになる間隔を取る。既定の解析では1回の押下から1秒以内の最初の試験音を探す。
3. 録音機のch1に「PTT押下中は正電圧、待機中は0」のマーカーを入れ、ch2以降に各受信車の音声を入れる。全チャンネルを同時収録した非圧縮16-bit PCM WAVにする。最初のPTTより前に無音とマーカーLowを入れる。
4. 出力段がブリッジ接続のアンプの場合、スピーカー線を録音機の接地入力へ直接接続しない。適切な減衰・絶縁・差動測定を用いる。テスト音と同じ周波数の通知音は無効化する。
5. 発話車を入れ替えて繰り返す。Host自身が発話するときは、許可の無線往復と発話車→Hostの無線送信がなくなるため別条件として扱う。

例（repoルート、ch1がPTT、ch2～6が5台の受信音声）：

```powershell
python tools/voice_latency_analyze.py .private/voice-latency/capture.wav --receiver-channels 2,3,4,5,6 --min-events 30 --deadline-ms 150 --output .private/voice-latency/report.json
```

終了コード0は、すべての受信チャンネルで30回以上、未着・無効試行が0、p95が150 ms以下の場合。その他は1。1 kHz音の検出しきい値が現物レベルに合わない場合は `--tone-level` を調整し、波形と検出位置を目視確認してから結果を採用する。p95はnearest-rank法で計算し、未着を成功試行の分位値へ混ぜず別件数として失敗判定する。録音ファイルのSHA-256をレポートに記録する。

## ボトルネックを特定するための端末ログ

上記の録音だけで製品体験の合否を測れるが、遅れの場所を特定するには各端末の単調時計で次の時刻を追加記録する必要がある。

| 端末 | 記録するイベント |
|---|---|
| 発話車 | PTT_DOWN、FLOOR_REQUEST送信、GRANT受信、最初の音声frame確定、VOICE送信 |
| Host/AP | REQUEST受信、GRANT送信、VOICE受信、各受信車への転送投入／完了 |
| 受信車 | VOICE受信、jitter buffer投入、再生準備完了、I2S書込み |

共通キーは`group_id`、`sender_id`、`stream_id`、`sequence`、受信車IDとする。**異なる端末の単調時計をそのまま引き算しない。** 同一端末内の区間だけログから計算し、全体のPTT→音声開始は共通クロック録音で判定する。USBシリアルのホスト到着時刻は無線遅延に含めない。

音声・無線の処理経路で逐次`printf`しない。時刻とキーを固定長バッファに記録し、試行後にまとめて取り出す方式で実装する。計測機能を有効／無効にした両方で遅延分布を比較し、計測負荷の影響を確認する。

## 現時点の境界

`firmware/experiments/voice_udp` は内蔵2.4 GHz Wi-Fiでの準備実験であり、HaLow・6台Host配信の実測はまだない。現在のHaLow実機は3台。録音解析ツールは用意済みだが、6台ファーム、同時録音用治具、日本向け適合モジュールとアンテナ、距離別の実測結果が揃うまでは「150 ms達成」とは扱わない。最初の1台が遠距離で遅れる可能性があるため、全5受信車の結果を保持する。
