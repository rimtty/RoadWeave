# RoadWeave UI Lab

同じツーリングIP-PTT体験を、3つのデザインで比較するWeb PoC。音声、接続、参加者、位置はすべて仮データです。マイクや位置情報の権限は要求せず、実際の音声は送信しません。

## 3つの方向

| 方向    | 主画面             | デザインの狙い                                           |
| ------- | ------------------ | -------------------------------------------------------- |
| Circle  | 仲間と発話者       | 柔らかな色、アバター、穏やかな輪で声の存在を伝える       |
| Pulse   | 前後の距離         | 大きな数字、暗い背景、ライムのアクセントで瞬時に読み取る |
| Compass | 自分中心の相対位置 | 紺色のレーダーに仲間と発話状態を重ねる                   |

`#circle` / `#pulse` / `#compass` で各案へ直接移動できます。

## 操作

- 左のデザイン選択で方向を切り替え。端末下部の「仲間・ライド・レーダー」または左右スワイプで画面切り替え。
- 右の「待受」にするとPTTを試せます。押して260ms後に仮の送信状態へ進み、離すと終了。短押し・切断・別画面への移動・フォーカス喪失で送信が残らない設計。
- 受信中はPTT送信を開始しません。仲間の発話終了後に押し直す方式を、このPoCのUX仮説にしています。実ファームウェアのBUSY_WAIT再試行動作とは別に評価してください。
- アバターや名前を選ぶと、個別音量・消音・個別PTT。個別PTTは相手を選ぶだけでは送信せず、物理ボタンを想定したPTTで送信します。
- グループ設定でメンバー・全体音量・退出。参加からのデモ、グループ作成、空のグループにも対応。
- 20秒のデモは6場面を順に再生。端末を操作すると停止します。「動きを控えめに」とOSの動きを減らす設定に対応。

## 実行と確認

Node.js 22.13以上。

```sh
cd design/web-poc
npm ci
npm run dev -- --host 127.0.0.1
npm run typecheck
npm run lint
npm test
npm run build
```

Lintは作成したアプリ、状態モデル、変更したSliderを対象とします。テンプレートの未使用UI部品は対象外です。TypeScriptはプロジェクト全体を確認します。

状態モデルの9テストは、送信許可前のリリース、切断、受信中の競合、キャンセル後の参加コールバック、音量、位置の鮮度、文字数、デザイン切り替えを検証します。

## 確認範囲と残る検証

2026-09-06、Mac Chromeで3案の表示と390px/320px幅を確認。参加、作成、個別音量のキーボード変更、消音、個別PTT選択、短いPTT操作、切断時の送信抑止を操作して確認しています。

PTT長押しのタイマーは状態モデルと実装で確認していますが、実際の指での長押し、スワイプ、車内視認性、実機のキーイベントは別途受入確認が必要です。Webの表示・アニメーションはLVGLのFPS・メモリ・音声同時処理性能を証明しません。

WebMCPは対応環境のみ `read_roadweave_preview` と `set_roadweave_scenario` を登録します。今回のブラウザー接続はWebMCP検証能力を提供していないため、ツール契約の実行検証は未実施。通常のUI操作には影響しません。

## LVGLへ移すとき

- 状態モデル、表示文言、色、部品の配置を移植対象にする。CSSそのものは移植しない。
- Circleのアバターは円とラベル、声の輪は少数の輪郭にする。Pulseはラベル・バー・矩形を中心に構成。Compassは固定目盛りと小さな位置マーカーを分ける。
- 常時動かすのは発話マーカーなどの狭い領域。全画面のぼかしや影はWebの演出であり、実機では背景画像か単色へ置き換える。
- このプレビューの縮小表示は寸法の目安。実際の240×320パネル向けにはフォント・余白・描画領域を再配置して評価する。
- 走行中は物理PTTと音量操作を中心にし、グループ編集や細かな音量調整は停車中の操作として検討する。
- S3でOpus・無線・LVGLを同時に動かした実測を、P4などへ進む判断材料にする。

デザインの参考文脈はAppleの情報階層・直接操作・意味のある動き、およびXiaomiの大きな数字・柔らかい形状・状態遷移です。固有製品の画面や商標表現はコピーしていません。
